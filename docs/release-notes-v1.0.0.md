## v1.0.0 — 首个可发布版本

桌面级 A 股**模拟交易**终端：**行情看盘 · 模拟交易 · 量化回测**，双击即跑。
**全程纯本地、纯模拟，无任何真实资金 / 券商接口 / 社交功能**。

### 🚀 一键下载

|------|------|---------|
| `A股模拟交易终端.exe` | 72.1 MB | `9882017e0f320bff0ad669d6c235c8582aae1d0b10f80a052133c19e0d282a72` |

> 双击即可运行，无需安装 Python。首次启动会自动在 `%APPDATA%\cn-stock-desktop\` 建库建配置。

### ✨ 功能

- **桌面直启形态**：单一 exe（PyInstaller 冻结），无终端 / 无服务 / 无环境
- **行情图表**：pyqtgraph K 线 + 成交量，支持日 K / 5/15/30/60 分钟、前/后复权、多均线叠加（5/10/20/60）
- **模拟交易**：买入/卖出、限价/市价、**T+1 制度**、整百手校验、涨跌停拒单、可用资金校验；持仓/委托/成交三张表实时渲染
- **量化回测**：内置 6 大策略（买入持有 / 双均线 / RSI / 布林带 / MACD / 网格）+ 收益 / 夏普 / 回撤指标
- **盘口与自选**：代码/名称搜索、自选股增删、单票实时盘口刷新
- **A 股规则**：T+1 / 涨跌停 / 100 股手 / 印花税（卖出单边千 0.5）/ 佣金（万 2.5 最低 5）/ 过户费（双边万 0.1）

### 🐛 主要修复

- 快速切换自选股竞态（用户反馈「其他示例股票打不开」）：引入单调 `_load_token`，`_on_data` / `_on_error` 写入前校验过期结果，stale 数据一律丢弃；附带离屏渲染证据（见 README）
- 实时行情 59 次分页请求缓存穿透：provider/manager TTL 对齐，TTL 内 6 次取数只触发 1 次真实请求
- akshare 请求超时真正生效（原 timeout 字段从未使用）
- 下单与定时刷新不再阻塞 UI 线程
- 离线体验：状态栏不再撒谎、不弹模态框轰炸、失败冷却
- 冻结后相对导入报错 → 顶层 `launcher.py` 入口修复
- `.bat` 多行中文 + 续行在 GBK 下解析炸 → 全部 `.bat` 退化为纯 ASCII 引导、复杂参数走 `.py`

### ⚡ 性能

- **打包体积**：124.7 MB → **72.1 MB（-42.2%）**
- 全市场快照缓存 TTL 对齐（30s ≥ 15s），避免每次刷新都重拉 59 个分页

### 🔧 构建 / CI

- GitHub Actions 自动打包（`windows-latest`，推送 `v*` 标签即触发）
- 打包前自检闸门：`_verify.py`（27 项断言）+ `_smoke.py`（撮合/回测/绩效）会先跑
- PyInstaller 缺失时 `build.py` 自装

### 🧪 测试

- `scripts/_verify.py`：持久化往返 / 交易视图渲染 / 离线失败冷却 / 快照缓存 / 股票列表降级开销 / 单票快路径 / **多只自选股离屏渲染（stale 丢弃）**
- `scripts/_smoke.py`：撮合引擎（T+1 / 整百 / 涨跌停 / 资金校验）/ 6 策略回测 / 绩效指标
- `scripts/_shot.py`：600519 / 000001 / 300750 三只示例股离屏渲染证据 → `docs/screenshots/market_proof_*.png`
